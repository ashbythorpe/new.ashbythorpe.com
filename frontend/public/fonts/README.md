# New Computer Modern text fonts

NewCM10-Regular.woff2 and NewCM10-Bold.woff2 come from New Computer Modern
8.1.1 (2026-06-22), by Antonis Tsolomitis:
https://ctan.org/pkg/newcomputermodern

Original files:
- https://mirrors.ctan.org/fonts/newcomputermodern/otf/NewCM10-Regular.otf
- https://mirrors.ctan.org/fonts/newcomputermodern/otf/NewCM10-Bold.otf

Converted to WOFF2 using fontTools, with the full glyph set and font metadata
preserved. No subsetting or glyph modifications were performed.

Regular: GPL version 3 or later with Font and Distribution Exceptions;
see NewComputerModern-LICENSE.txt.
Bold: GUST Font License; see GUST-FONT-LICENSE.txt.

These text fonts are separate from the existing NewCMMath-Regular.woff2
used for mathematical typesetting.
